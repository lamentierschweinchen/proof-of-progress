## Themes

### Staking v5, year 2 inflation

- [api #1661](https://github.com/multiversx/mx-api-service/pull/1661) adds the second `stakingV5Inflation` value. The PR says `getApr()` throws once the year index becomes 1 without it. Mainnet: 1,372,128, computed as 50% × 8.757% × a projected supply of 31,337,853 at epoch 2316. Devnet (1,162,631) and testnet (1,013,066) get their own values. The PR notes these can be refined with real supply once each network reaches that epoch.
- [delegation-service #18](https://github.com/multiversx/mx-delegation-service/pull/18) (outside the watchlist, merged to `main`) adds year 2 with a maximum inflation of 0.08757, which it calls the protocol tail inflation, with decay not yet implemented. Its description says provider APR would drop to 0 from epoch 2316 without the entry.
- **Open item:** the API value is [on `development`](https://github.com/multiversx/mx-api-service/blob/development/config/config.mainnet.yaml) and not on [`main`](https://github.com/multiversx/mx-api-service/blob/main/config/config.mainnet.yaml). What the hosted API and delegation service currently run is not visible from GitHub.

### Proxy release

- [v1.5.4](https://github.com/multiversx/mx-chain-proxy-go/releases/tag/v1.5.4) (pre-release): [#524](https://github.com/multiversx/mx-chain-proxy-go/pull/524) is the only PR in the release notes. It fixes the process-status check for eligible same-shard records, including refunds.

### API dependencies and CI

- [api #1667](https://github.com/multiversx/mx-api-service/pull/1667) moves the `sdk-nestjs` packages to 7.4.0, so locally cached values are capped at the remaining Redis TTL. **Operator note:** Redis read metrics on the affected paths are now labeled `GETWITHTTL` / `MGETWITHTTL` instead of `GET` / `MGET`; dashboards and alerts filtering on the old labels need updating.
- [api #1666](https://github.com/multiversx/mx-api-service/pull/1666) fixes the k6 install step in load tests on Ubuntu 26.04.
- The [websocket subscriptions PR #1625](https://github.com/multiversx/mx-api-service/pull/1625) took in the new `development` changes and remains open.
