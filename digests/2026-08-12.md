## Themes

### Altered-accounts correctness fix closes a real indexing gap

`#7956` is a small but concrete fix: any tool reading "altered accounts" per block (indexers, explorers, anything reconciling state deltas) was silently missing newly-deployed smart contracts, because the provider only looked at transaction senders and receivers — a deploy transaction's receiver is the system deploy address, not the new contract. Scanning `SCDeploy` event logs for the deployed address closes that gap. Small in diff size (+250/−0) but the kind of fix that matters disproportionately for downstream consumers of chain data.

Today confirms the values are still stale at the source. Worth flagging directly rather than re-verifying identically each day if it doesn't move again soon.
