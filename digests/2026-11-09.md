## Themes

### API service hardening lands

- [#1658](https://github.com/multiversx/mx-api-service/pull/1658): the 64 MB NFT media limit was only checked against the declared `content-length` of the HEAD response; thumbnail and asset GETs buffered the whole body unbounded, and gzip decompression could inflate a small body into a very large one. The cap now applies to the downloaded data.
- [#1659](https://github.com/multiversx/mx-api-service/pull/1659): `RestrictedRoutesMiddleware` compared the raw `req.path`, so other spellings of a restricted path could reach it (the PR cites `/docs/package.json`). Paths are now normalized first.
- [#1660](https://github.com/multiversx/mx-api-service/pull/1660): `POST /query` and `POST /vm-values/query` cache keys did not include `value`, though `value` is sent to the gateway and changes the result. Public VM queries are no longer cached.
- No release tag yet; latest is [v1.21.0](https://github.com/multiversx/mx-api-service/releases/tag/v1.21.0) (Aug 19).

### Staking v5 year 2

- [#1661](https://github.com/multiversx/mx-api-service/pull/1661): adds year-2 inflation values for mainnet, devnet and testnet so APR calculation keeps working past the first year of staking v5.

### SDK and contract framework gas model

- [mx-sdk-rs #2437](https://github.com/multiversx/mx-sdk-rs/pull/2437): a gas-cost regression fix for large `ManagedVec` storage entries, behind a flag. Same author as the vm-go executor work.
- [mx-sdk-js-core #686](https://github.com/multiversx/mx-sdk-js-core/pull/686): `feat/next` caught up with `main`; latest stable stays [v16.0.0](https://github.com/multiversx/mx-sdk-js-core/releases/tag/v16.0.0).
