## Themes

### Release-candidate consolidation continues, one branch at a time

Yesterday's `#7853` merge folded weeks of `feat/testnet-fixes` work into `rc/supernova` directly. Today's `#7972` shows the same pattern still running one layer down: work keeps landing on `refactor-contended-headers-gate` (itself queued behind the still-open `#7971`) rather than going straight to the release branch. Worth watching whether `#7971` merges as a unit the way `#7853` did, and whether a new `mx-chain-go` pre-release tag follows.

### `mx-sdk-dapp` quietly re-tunes for a 10x-faster chain

This is the clearest evidence yet that the dApp SDK layer is adapting to Supernova's round-time drop, not just the node and config repos. The constants match exactly what `mx-sdk-core`'s `TransactionWatcher` already assumes (600ms poll cadence) — `sdk-dapp` catching up to the same clock. The selector fix is arguably the more consequential half: without it, a transaction batch that fully settles to `success` while sitting in the tracker could be invisible to `useGetSuccessfulTransactionsSessions()` and mis-categorized against the `sent` state instead — exactly the kind of bug a 10x round-time drop would newly expose (batches settle before the old assumptions catch up). Still pre-PR, alpha-versioned, no review yet — flag for next digest to see if a PR opens and how this is described once accompanied by real reasoning.

### Stuck items unchanged

`#7951` (sixteenth digest, no commits since Aug 10) and `mx-sdk-rs` `rc/v0.67` `#2378` (unchanged since Aug 13) both sit exactly where they were yesterday.
