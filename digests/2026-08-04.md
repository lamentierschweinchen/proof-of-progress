### The "99999999999" commits are a false alarm, worth naming so it doesn't get miscounted next digest

Both [#7944](https://github.com/multiversx/mx-chain-go/pull/7944) and [#259](https://github.com/multiversx/mx-chain-mainnet-config/pull/259) picked up a commit with the same title pattern ("99999999999 supernova round") within a day of each other. The actual diffs (checked directly, not inferred from commit titles) show both are widening an already-far-future placeholder (`999999999`/`99999999` → `99999999999`) across `EnableRound`/`Round` fields — the same placeholder pattern that's existed in these files with an explicit `# TODO: ... this is enforced at node startup` comment marking the real value as still pending. No evidence either way on whether the Aug 6 target itself moved; that would show up as a *different* number, not a wider placeholder.
