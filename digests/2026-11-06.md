## Themes

### VM executor: opcode versioning

- [#989](https://github.com/multiversx/mx-chain-vm-go/pull/989): adds `executor.OpcodeVersion` (V1/V2), selected by the new `OpcodeV2Flag`. V2 whitelists and meters `memory.copy` and `memory.fill` (flat plus per-byte cost, added to the V3 and V4 gas schedules). `SetOpcodeCosts` is replaced by `SetOpcodeConfig(version, costs) error`; a nil cost table is now rejected instead of metering at zero. Per the PR body, V2 also drops legacy exception-handling opcodes, and the wasmer2 binary is updated to match a companion Rust executor change. Ported from #943 (originally based on `rc/after-supernova`; history not preserved).
- Behavior is flag-gated; activation epoch not stated in the PR. [#997](https://github.com/multiversx/mx-chain-vm-go/pull/997) (draft) extends this toward Wasmer 7 and a new FFI.

### API service hardening

- [#1656](https://github.com/multiversx/mx-api-service/pull/1656): NFT media fetches now enforce public addresses at connect time (`publicHttpsAgent`, `net.BlockList`, all resolved addresses must be public); previous check ran only before the media `HEAD` and missed IPv4-mapped IPv6 and other reserved ranges (+221/-67).
- [#1657](https://github.com/multiversx/mx-api-service/pull/1657): Docker entrypoint no longer prints `CFG_*`/`DAPP_*` values (which included secrets) to container logs.

### SDK / tooling

- [mx-sdk-rs #2436](https://github.com/multiversx/mx-sdk-rs/pull/2436) system SC proxy fixes opened; scope not examined.
