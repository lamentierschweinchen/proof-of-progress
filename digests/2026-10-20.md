### Rust framework: release-candidate prep

- `sc-meta` codehash commands [#2429](https://github.com/multiversx/mx-sdk-rs/pull/2429): adds generate, print, verify and clear commands for WASM codehashes in the reproducible-build tooling (+763/-30, 13 files), extended to Git-based framework dependencies. The PR says it was used to trace legacy delegation historical code hashes, which lines up with the `mx-delegation-sc` activity the same day.
- Dependency upgrades [#2431](https://github.com/multiversx/mx-sdk-rs/pull/2431): updates manifests, lockfiles and CI toolchains across SDK, framework, VM and tools (+1932/-2654, 39 files), adapts proc macros, mnemonic generation and debugger formatting, and fixes `sc_panic!` in expression position with regression tests.
- Lint and unused-dependency cleanup [#2432](https://github.com/multiversx/mx-sdk-rs/pull/2432): clears clippy and cargo warnings under newer Rust toolchains, described as semantics-preserving (+124/-330, 51 files).

### Indexing correctness

- ESDTTransfer dedup [#1650](https://github.com/multiversx/mx-api-service/pull/1650): the old logic dropped every `ESDTTransfer` event with identical content, including legitimate same-shard repeats (example in the PR: 4 events returned as 2). It now deduplicates only across shards, which is the case it was meant to cover.
