## Themes

### Rust framework: audit fixes

[#2446](https://github.com/multiversx/mx-sdk-rs/pull/2446) ("Audit fixes, part 1") describes the changes as bugs and issues "found by Mythos". The first two were checked against the [v0.66.3](https://github.com/multiversx/mx-sdk-rs/releases/tag/v0.66.3) source, which has the old code.

- **Decimal comparison:** in `ManagedDecimal` and `ManagedDecimalSigned`, when the left value has more decimals than the right, the ordering comparison had its operands reversed. The fix restores the order. The patched lines are in `partial_cmp`.
- **`u128` codec:** in v0.66.3, top-level encoding casts a `u128` to `u64`, and top-level decoding reads through a 64-bit path. The fix handles the full 128-bit range and adds boundary tests. Nested encoding already used all 16 bytes.
- **Test generators:** `sc-meta scen-blackbox` and `sc-meta test-gen` now escape or sanitize text from scenario files, ABIs and file names before writing it into generated Rust code, to prevent code injection.
- [#2447](https://github.com/multiversx/mx-sdk-rs/pull/2447) merges `master`, including these fixes, into `rc/v0.67`.

### Rust SDK: API support on the 0.67 branch

- [#2442](https://github.com/multiversx/mx-sdk-rs/pull/2442) (+800/-4) adds API data types and HTTP calls for accounts, contracts, events and transactions, with examples. It targets `rc/v0.67`; the [v0.67 release candidate PR](https://github.com/multiversx/mx-sdk-rs/pull/2378) is still a draft.

### Paginated account and token listings

- [proxy #525](https://github.com/multiversx/mx-chain-proxy-go/pull/525) (draft, +3193/-492) adds checkpoint pagination for account and ESDT listings over GET and POST. Legacy GETs return an error if a listing exceeds one page. Checkpoint continuation is limited to three distinct observer attempts. It uses the same branch name as [mx-chain-go #8060](https://github.com/multiversx/mx-chain-go/pull/8060), "Paginate trie traversal on api".
